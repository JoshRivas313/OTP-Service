Cómo está hecho

  • Java 21 y Spring Boot 4 El backend que genera, envía y verifica cada código.
  • Arquitectura hexagonal El núcleo no depende del SMS, del correo ni de la base de datos.
  • Secretos cifrados con AES-256-GCM Los secretos de HOTP y TOTP nunca se guardan en claro.
  • MongoDB opcional Sin base de datos, todo vive en memoria y arranca con un comando.
